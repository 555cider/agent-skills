# 스킬 신뢰성 개선 (2026-09-17)

`swear`를 제외한 8개 스킬의 실행·복구·호출 경계를 개선한다. 아래 변경은 저장소에 반영했으며, 대상 플러그인 버전은 1.1.0이다.

## 변경 사항

| 스킬 | 개선 내용 |
| --- | --- |
| plan-graph | `close --force`를 완료 우회가 아닌 포기로 처리하고, 활성 후속 계획이 있으면 거부한다. 삭제 전 원본을 복구 사본으로 보존한다. Windows 잠금 소유자 확인을 조회 전용으로 바꾼다. |
| worktree-cycle | 사용자별 공용 포트 예약 장부와 OS 잠금으로 동시 배정을 조정한다. 자동·명시 포트 모두 예약 중복과 실제 bind 가능성을 확인한다. |
| dom-picker | queue에 기존 consumer·phase·편집 검토 필요 여부를 제공하여 중단된 작업을 같은 소유자로 재개할 수 있게 한다. |
| agent-memory | `forget` 결과에 삭제·보존 범위를 명시한다. 기억 도입과 전역 trust 설정 변경의 권한을 분리한다. |
| screen-map | 안전한 탐색 경로가 없다는 이유로 허용 목록을 확대하지 않는다. 기존 권한 안에서 관찰하거나 승인된 경로를 사용한다. |
| peer-review | 일반 추천과 외부 리뷰 요청을 구분한다. 명시적인 외부 리뷰 요청에는 중복 확인 없이 진행한다. |
| ui-audit | 요소·컴포넌트·화면별 감사 범위를 구분한다. 한국어 버튼 명사형 규칙은 명시적으로 선택할 때만 적용한다. |
| step-back | 요청 전체의 누락을 확인하고 필수 개선과 선택적 개선을 구분한다. 반복 횟수만으로 중단하지 않고 새로 얻을 정보에 따라 계속·전환을 판단한다. |

## 사용 시 주의사항

- **계획 복구:** 복구 사본 저장에 실패하면 삭제하지 않는다. 사본은 자동 정리하지 않는다.
- **포트 배정:** Python 3.10+가 필요하다. 예약은 OS 포트 점유가 아니므로 서버의 strict bind와 응답 확인은 여전히 필요하다. 다른 OS 사용자나 미등록 구버전 예약까지 보장하지 않는다.
- **DOM 재개:** 이전 작업자가 종료됐는지와 기존 편집을 확인한 뒤 재개한다. 자동 소유권 탈취는 하지 않는다.
- **기억 삭제:** 이벤트·관리 백업·외부 export는 자동 삭제하지 않는다. 재유입 방지는 기존 7일 tombstone 범위다.
- **한국어 버튼 규칙:** `auditConfig.copy.koButtonNounStyle: true`일 때만 명사형 선호를 검사한다. 자연스러운 한국어 동작명은 유지한다.

`swear`와 해당 플러그인 항목은 변경하지 않았다. 설치된 스킬 교체와 전역 설정 변경은 포함하지 않는다.
